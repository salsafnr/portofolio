## Overview

An end-to-end prototype for real-time bearing envelope signal analysis, with a desktop application and WhatsApp alerts for early fault detection.

It covers the full chain from sensor signal to ESP32 acquisition, Python analysis software, and alerts. I built it with the electrical instrumentation engineer who designed the signal-conditioning hardware.
