## Overview

PT Solusi Bangun Indonesia Tbk is a cement manufacturer under the SIG Group. I build software and digitalization projects for the maintenance department.

## What I did

- Built 3 PHP/MySQL web applications: a motor condition monitoring system (vibration, envelope, temperature, grease, about 200 motors registered) with a self-built WhatsApp alert bot; digital calibration forms replacing a paper-based process; and a training record system for 90+ maintenance staff.
- Introduced the applications to maintenance staff and actively sought out users for feedback and suggestions to refine the features.
- Developed a linear-regression soft sensor that estimates fan motor vibration readings from correlated sensors. It has run in the DCS since March 2026 to check suspicious over-limit readings before an automatic shutdown, which is costly to restart from.
- Built a vibration monitoring prototype covering the full chain from sensor signal to ESP32 acquisition, Python analysis software, and alerts, working with the electrical instrumentation engineer who designed the signal-conditioning hardware.
